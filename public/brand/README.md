# Ubunifu Technologies Brand Assets

These files are generated from the same orange U and violet T ligature used by the website.
All SVG and PNG files have transparent backgrounds.

## Everyday Use

- `ubunifu-mark.svg`: symbol only for favicons, avatars, and small signatures.
- `ubunifu-lockup.svg`: preferred horizontal logo for light backgrounds.
- `ubunifu-wordmark.svg`: text-only wordmark for layouts where the mark appears elsewhere.
- `ubunifu-lockup-stacked.svg`: centred mark and wordmark for square or portrait spaces.

## Reversed Use

- `ubunifu-mark-inverse.svg`: coloured mark tuned for a dark field.
- `ubunifu-lockup-white.svg`: coloured mark with a white wordmark.
- `ubunifu-wordmark-white.svg`: white text-only wordmark.

## Watermarks

- `ubunifu-watermark.svg`: low-opacity mark for document and image overlays.
- `ubunifu-watermark-lockup.svg`: low-opacity horizontal lockup.

## PNG Exports

The `png` directory contains large transparent raster exports for tools that cannot use SVG.
Run `npm run brand:export` after changing the canonical mark or horizontal lockup.

Do not stretch, recolour, box in, or add effects to the master assets.
