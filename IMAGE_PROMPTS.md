# Image prompts

21 complete prompts. Each one is self-contained - paste the whole block into ChatGPT as
a single message, nothing to assemble. Then export to WebP and save to the exact path
given. Every path is already wired into the code, so replacing the file is the only
step; no code changes are needed.

    cwebp -q 82 downloaded.png -o public/editorial/<filename>

Keep page headers under 150 KB and the rest under 100 KB. The audience is mid-range
Android on metered data.

**Not in this list:** the six system diagrams (operations, enquiry, web, hosting, data,
ai) stay as code-drawn SVG and are being redrawn in the flat isometric style. Generated
images would be worse for those - they need to stay crisp, themeable and tiny.

---
